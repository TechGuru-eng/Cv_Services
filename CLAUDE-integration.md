# CLAUDE.md integration

## Mandatory Frontend Skill

For every frontend, website, dashboard, landing page, component, form, UI redesign, or responsive-design task:

**Invoke the `frontend-design` skill before writing code.**

Do not skip the skill for small visual changes.

If a reference screenshot or mockup is provided, use the skill's Reference Image Mode and visual QA loop.

If no reference is supplied, use its Design-from-Scratch Mode.

Always perform a rendered visual review before considering significant frontend work complete when preview/screenshot tools are available.
